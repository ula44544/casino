# 🎰 SLOT MACHINE — Консольный слот-автомат на C++

Консольная мини-игра в стиле классического казино с анимацией прокрутки, цветными символами и системой ставок.

Программа поддерживает цветной вывод, проверку ввода, систему выигрышей и работает как на Windows, так и на Linux/macOS.

---

## 📌 Описание проекта

«SLOT MACHINE» — это консольный игровой автомат, написанный на C++.

Игрок получает стартовый баланс и делает ставки на вращение слотов.  
После прокрутки отображаются три случайных символа:

- 🎰 3 одинаковых символа → ДЖЕКПОТ x5
- 🎲 2 одинаковых символа → Победа x2
- ❌ Нет совпадений → проигрыш ставки

Игра продолжается, пока у игрока остаются поинты.

## 🎮 Игровая механика

Игрок начинает с балансом:

```txt
1000 поинтов
```

После ввода ставки запускается анимация вращения слотов.

Пример:

```txt
[ 7 ] [ $ ] [ 7 ]
```

Результаты:

```txt
3 одинаковых символа → x5
2 одинаковых символа → x2
Нет совпадений      → проигрыш
```

## 🧠 Особенности реализации

В проекте реализованы:

- Структура `Symbol` для хранения символа и цвета
